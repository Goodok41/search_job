# search_job

Программа разбирает сохранённые вакансии продуктового аналитика с hh.ru и показывает, в какой доле вакансий встречается каждый навык.

## Установка и запуск

```bash
git clone https://github.com/Goodok41/search_job.git
cd search_job
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

mkdir -p inbox
cp examples/*.html inbox/ 
python main.py
```

Запускать из папки `search_job`. Результат — таблица навыков в терминале и в `data/skills.csv`.

Свои вакансии: сохранить страницу hh.ru в `inbox/` (только HTML»), затем `python main.py`. 
Вакансии запоминаются между запусками в `data/vacancies.json`.

## Как устроено

- `input_info.py` — разбирает HTML одной вакансии
- `collection.py` — собирает папку `inbox/` в словарь по id
- `save_read.py` — сохраняет и загружает вакансии в JSON
- `skills.py` — ищет навыки по словарю синонимов `synonyms.json`
- `report.py` — считает долю вакансий с каждым навыком, выводит таблицу и CSV
- `vacancy.py`, `errors.py` — класс вакансии и своя ошибка `ParseError`
- `main.py` — запускает всё одной командой

## Краевые случаи

- вакансия сохранена дважды — учитывается один раз (словарь по id);
- нет блока «Ключевые навыки» — навыки ищутся в описании;
- разные написания («AB тесты», «A/B») — сводятся к одному навыку;
- пустой файл или не та страница — пропускается, в конце список с причинами;
- неразрывные пробелы hh — заменяются обычными.

## Ограничения

- В сеть программа не ходит: публичный API hh.ru закрыт.
